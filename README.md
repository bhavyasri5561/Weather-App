# Weather App

A simple, responsive weather application built using HTML, CSS, and JavaScript.

## Features
- Search weather by city name
- Display temperature and weather conditions
- Show humidity and wind speed
- Responsive user interface
- Fetch real-time weather data using the OpenWeatherMap API

## Technologies Used
- HTML
- CSS
- JavaScript
- Fetch API
- OpenWeatherMap API

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Run `index.html` using Live Server.
4. Enter a city name and click Search.

## Security Note
Do not commit API keys or other secrets to a public repository.
